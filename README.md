# Trail-log
Tracking app mit strava auswertung

## Linux-Version

Unter *Releases* → `linux-latest`: `Trail-Log-….AppImage` (ausführbar machen und starten) oder `Trail-Log-….rpm` für Fedora (`sudo dnf install ./Trail-Log-*.rpm`).
Touren vom Handy: in der App Backup exportieren und am PC über „Backup laden“ einlesen. Gespeicherte Dateien landen in `~/Downloads/Trail Log` bzw. `~/Bilder/Trail Log`.
