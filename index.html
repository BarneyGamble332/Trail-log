Einstellungen

Version __BUILD__

Bereits importierte Touren werden übersprungen, du kannst also jederzeit einen neueren Export nachladen. Touren aus älteren Versionen bekommen dabei Höhenprofil und Bewegungszeit nachgetragen. Alles bleibt auf diesem Gerät.

So bekommst du den Strava-Export

  1. strava.com im Browser öffnen, anmelden
  2. Einstellungen → Mein Konto → „Konto herunterladen oder löschen“ → Los geht’s
  3. „Anfrage senden“ (Schritt 2). Strava schickt dir einen Download-Link per E-Mail.
  4. Die ZIP-Datei hier laden, ohne sie zu entpacken.
